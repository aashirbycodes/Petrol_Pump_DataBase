# Petrol Pump Management System (PPMS)

## About
Petrol Pump Management System is a database project developed using MySQL. It manages daily petrol pump operations and maintains records of customers, employees, fuel, suppliers, sales, payments, and inventory.

## Features
- Customer and Employee Management
- Fuel and Fuel Tank Management
- Fuel Purchase and Supplier Records
- Fuel Dispenser Management
- Sales and Payment Management
- Vehicle Records
- Cleaning Activity Management
- SQL Queries for Data Management and Reports

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Database Entities
Cashier, Cleaner, Cleaning Activity, Customer, Employee, Fuel, Fuel Dispenser, Fuel Purchase, Fuel Tank, Manager, Payment, Sale Transaction, Supplier, Vehicle.

## Purpose
This project was developed as part of a Database Management System course to practice database design, SQL queries, relationships, and data management.
